# Python 90 Days Challenge

## Day 02 – Fresher Interview Questions

### 1. What is a variable in Python?

A variable is a name used to store a value in memory.

### 2. How do you take input from the user in Python?

We use the `input()` function to take input from the user.

### 3. What type of value does `input()` return?

The `input()` function returns the user's input as a **string** by default.

### 4. What is an identifier in Python?

An identifier is the name given to variables, functions, classes, and other objects in Python.

### 5. What are the rules for naming identifiers?

An identifier can contain letters, digits, and underscores. It cannot start with a digit and cannot be a Python keyword.

### 6. What are Python keywords?

Keywords are reserved words that have a special meaning in Python, such as `if`, `for`, `class`, and `def`.

### 7. Can we use a keyword as a variable name?

No. Python keywords cannot be used as identifiers.

### 8. What is an expression in Python?

An expression is a combination of values, variables, and operators that produces a result.

Example:

```python
a + b
```

### 9. What is the difference between a variable and an identifier?

A variable is used to store a value, while an identifier is a name used to identify programming elements such as variables, functions, and classes.

### 10. What is the difference between `=` and `==` in Python?

`=` is the assignment operator used to assign a value, while `==` is the comparison operator used to check whether two values are equal.
