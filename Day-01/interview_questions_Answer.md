# Python 90 Days Challenge
# Day 01 - Interview Questions & Answers

## Q1. What is Python?

**Answer:** Python is a high-level, general-purpose programming language used for automation, web development, data handling, AI, Machine Learning, scripting, testing, and backend development.


## Q2. Who created Python?

**Answer:** Python was created by Guido van Rossum.


## Q3. When was Python first released?

**Answer:** Python was first released in 1991.


## Q4. What are the main features of Python?

**Answer:** Python has simple syntax, is high-level and interpreted, dynamically typed, object-oriented, cross-platform, open-source, and has large library support.


## Q5. Why is Python called a high-level language?

**Answer:** Python is called a high-level language because programmers can write code without dealing directly with machine-level details.


## Q6. What does interpreted language mean?

**Answer:** Python programs are executed using an interpreter rather than being directly executed as machine code.


## Q7. What are the advantages of Python?

**Answer:** Python is easy to learn, has simple syntax, provides large library support, is useful for automation and many industries, and is free and open-source.


## Q8. What are the applications of Python?

**Answer:** Python is used for web development, automation, data science, AI, Machine Learning, testing, scripting, and backend development.


## Q9. What is the Python Interpreter?

**Answer:** The Python Interpreter is the program that executes Python code.


## Q10. What is indentation in Python?

**Answer:** Indentation is the spacing used at the beginning of a line to define blocks of code in Python. Four spaces are commonly used.
