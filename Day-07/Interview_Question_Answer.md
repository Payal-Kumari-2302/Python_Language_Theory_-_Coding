# Day-07: Python Interview Questions

## 1. What are nested conditions in Python?

**Answer:** Nested conditions are conditional statements written inside another conditional statement.

**Real-World Example:** An ATM checks the account balance before allowing a withdrawal.

## 2. What is the ternary operator in Python?

**Answer:** The ternary operator is a short way to write an `if-else` statement in one line.

**Real-World Example:** Checking whether a customer is eligible for a discount.

## 3. What is the `match-case` statement in Python?

**Answer:** The `match-case` statement executes a block of code based on the matching case.

**Real-World Example:** Selecting an option from an ATM menu.

## 4. What are truthy and falsy values in Python?

**Answer:** Truthy values behave like `True`, while falsy values behave like `False` in conditions.

**Real-World Example:** Checking whether a username field is empty in a login form.

## 5. What is the purpose of `case _` in Python?

**Answer:** `case _` acts as a default case when no other case matches.

**Real-World Example:** Displaying an error message for an invalid calculator operator.
