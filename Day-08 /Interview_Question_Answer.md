## Day 08 – Interview Questions
### Topics: for Loop and while Loop

### Q1. What is a loop in Python?

**Definition:** A loop is used to execute a block of code multiple times.

**Purpose:** To repeat code without writing the same statements again and again.

**Real-World Example:** Displaying the names of multiple students one by one.

### Q2. What is a for loop in Python?

**Definition:** A `for` loop is used to repeat code over a sequence.

**Purpose:** To process items in a string, list, tuple, or range.

**Real-World Example:** Printing each character of the word "Python".
