# Python 90 Days Challenge

## Day 04 – Fresher Interview Questions

### 1. What is an operator in Python?

An operator is a symbol used to perform an operation on values or variables.

### 2. What are the different types of operators in Python?

The main types of operators are **Arithmetic, Comparison, Logical, Assignment, Membership, Identity, and Bitwise operators**.

### 3. What are arithmetic operators in Python?

Arithmetic operators are used to perform mathematical operations such as addition, subtraction, multiplication, division, remainder, floor division, and power.

Examples: `+`, `-`, `*`, `/`, `%`, `//`, `**`

### 4. What is the difference between `/` and `//` in Python?

`/` is used for normal division, while `//` is used for floor division.

### 5. What is the use of the `%` operator?

The `%` operator returns the remainder after division.

Example:

```python
10 % 3
```

Output:

```text
1
```

### 6. What is the use of the `**` operator?

The `**` operator is used to calculate the power of a number.

Example:

```python
2 ** 3
```

Output:

```text
8
```

### 7. What are comparison operators in Python?

Comparison operators are used to compare two values and return either `True` or `False`.

Examples: `>`, `<`, `>=`, `<=`, `==`, `!=`

### 8. What is the difference between `=` and `==` in Python?

`=` is the assignment operator used to assign a value, while `==` is the comparison operator used to check whether two values are equal.

### 9. What are logical operators in Python?

The logical operators in Python are `and`, `or`, and `not`.

### 10. What does the `and` operator do?

The `and` operator returns `True` when both conditions are true.

### 11. What does the `or` operator do?

The `or` operator returns `True` when at least one condition is true.

### 12. What does the `not` operator do?

The `not` operator reverses the Boolean result.

### 13. What are assignment operators in Python?

Assignment operators are used to assign or update values in variables.

Examples: `=`, `+=`, `-=`, `*=`, `/=`

### 14. What is the use of the `+=` operator?

The `+=` operator adds a value to a variable and assigns the updated value back to the variable.

Example:

```python
x = 10
x += 5
```

Here, `x` becomes `15`.

### 15. What are membership operators in Python?

Membership operators are used to check whether a value exists in a sequence or collection.

The membership operators are `in` and `not in`.

### 16. What are identity operators in Python?

Identity operators are used to check whether two variables refer to the same object.

The identity operators are `is` and `is not`.

### 17. What is the difference between `==` and `is`?

`==` compares the values of two objects, while `is` checks whether two variables refer to the same object.

### 18. What are bitwise operators in Python?

Bitwise operators perform operations on the binary representation of numbers.

Examples: `&`, `|`, `^`, `~`, `<<`, `>>`

### 19. What is operator precedence in Python?

Operator precedence determines the order in which operators are evaluated in an expression.

### 20. What will be the output?

```python
a = 10
b = 3

print(a + b)
print(a // b)
print(a % b)
```

Output:

```text
13
3
1
```

### 21. What will be the output?

```python
x = 10
x += 5

print(x)
```

Output:

```text

```

### 22. What will be the output?

```python
print(10 > 5)
print(10 == 5)
```

Output:

```text
True

```

```python

```

Output:

```text

```

```

Output:

```

### 25. Why are operators important in Python?

Operators are used to perform calculations, comparisons, logical operations, assignments, and other operations on data.
